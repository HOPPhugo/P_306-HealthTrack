# Contexte du projet

## Description

Le but du projet est de produire une application de suivi de santé avec google appsheet.

## Objectif
Quel est le but de l'application ?

Entrer ses données dans une interface à remplir qui seront stockées dans une base de données accessible a tout moment.

## Utilisateur cible
Pour qui est faite l’application ?

Pour les gens qui veulent traquer leur santé pour leur bien être ou pour les sportifs qui veulent voir leur evolution. 

## Périmètre
### Inclus
-entré de données
-Stockage de données
-visualisation de données

### Exclus
-synchronisation avec une montre
-entrée automatique des données a partir de l'effort (BPM,vitesse,etc)
